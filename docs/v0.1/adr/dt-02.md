# DT-02 — Build the desktop GUI with Tauri 2, React and TypeScript

**Status** — Approved roadmap decision.

**Source** — *Arquitetura e Roadmap v0.1*, DT-02, consulted November 13, 2026.

**Baseline provenance** — [Phase 0 compatibility baseline](../baseline.md).

## Context

Corinthos Core is planned as a local desktop product. Its existing Python
services supply the behavior the desktop must expose.

## Decision

Use Tauri 2 for the desktop shell and React with TypeScript for the frontend.
Use a modern bundler compatible with Tauri.

## Rationale

This stack supports a separate visual layer while retaining local-first
operation and a Python backend.

## Alternatives

- Electron would add a dedicated Chromium process and a larger footprint
  without a proportionate benefit.
- PySide6 offers direct Python integration but reduces visual flexibility,
  future reuse and separation between the interface and domain.
- A web or SaaS application would bring hosting, authentication and exposure
  of private source code into the product prematurely.

## Consequences and compatibility

The GUI uses the [shared Application API](dt-06.md) through the
[local IPC bridge](dt-04.md). Existing contracts and headless subcommands
remain in the Python backend.

## Affected phases

Phase 1 proves the desktop stack with a skeleton and backend spike.
Phases 2–8 add screens for domain capabilities. Phase 9 hardens and
integrates source installation of the desktop.

## Scope exclusions

Phase 0 records the stack choice. Desktop code, dependency or toolchain
changes and a public desktop release belong to later work.
